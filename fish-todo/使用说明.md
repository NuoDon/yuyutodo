# 鱼鱼清单 · 使用说明

一个装在手机里的待办清单：每天 / 每周 / 每月自动重复的事、临时的事、一件分成好几步的事，
都能记，勾一步涨一点进度，快到期没做完会提醒你，还能一键同步到系统日历，让手机自己的闹钟响起来。

整个程序就一个文件：`index.html`。没有服务器，没有账号，数据全在你手机的浏览器里。

---

## 一、放到手机上

### 方式 A：最快（30 秒）

1. 把这个 `index.html` 通过 QQ / 微信「文件」发给手机
2. 在手机上点它 → 选**「用其他应用打开」** → 挑一个浏览器（Chrome、Edge、夸克、小米浏览器都行）
   - 如果 QQ 自带浏览器直接打开了，也行，但**以后请固定用它**，不然数据会各存各的
3. 能用。建议加个书签，或者把文件存到「文件管理 → 下载」里固定位置

> ⚠️ 数据存在「你用的那个浏览器」里。所以固定用一个浏览器打开，
> 不要今天用 QQ 浏览器、明天用 Chrome —— 那是两个独立的存储。

> 💡 有些手机浏览器（小米、vivo、华为、夸克）对**本地文件**也能「添加到桌面」，
> 菜单里翻一下，有的话直接点，比方式 B 还快。

### 方式 B：要个桌面图标（推荐，2 分钟）

1. 随便找一个能放网页的地方，把 `index.html` 传上去，拿到一个网址。
   最省事的几个：
   - **Gitee Pages**（国内快，免费）
   - **GitHub Pages**（免费）
   - **Vercel / Netlify**（拖一个文件进去就行）
2. 手机浏览器打开这个网址
3. 右上角菜单 → **「添加到主屏幕」/「添加到桌面」**
4. 桌面上就多了一个图标，点开全屏运行，跟 App 一样

### 方式 C：真正的 .apk 安装包

安卓工程已经写好了，就在这个文件夹里。看 **`怎么变成APK.md`**：

- 上传到 GitHub，它免费帮你编译，下载 apk 就行（不用装任何软件）
- 或者用 Android Studio 本地编译

装出来跟网页版功能一样，只是多了一个独立图标、独立存储，日历导出走原生也更稳。

## 二、四分钟学会用

### 新建一件事

点右下角的 **＋**

| 字段 | 说明 |
|---|---|
| 要做什么 | 任务名字 |
| 什么时候 | **每天 / 每周 / 每月 / 一次性** 四种 |
| 几点开始 | 这一天什么时候做 |
| 大概做多久 | 用来算「截止时间」= 开始时间 + 时长 |
| 开始前提醒 | 提前几分钟提醒你该动了 |
| 快截止时再提醒 | 还剩几分钟没做完时提醒你 |
| 分成几步完成 | 一件大事拆成小步，比如「写周报」拆成「整理数据 / 写总结 / 检查错字」 |

**四种「什么时候」：**

- **每天** —— 可以填「每几天」，填 1 就是每天，填 2 就是隔一天
- **每周** —— 选星期几，可以多选（比如周一到周五）
- **每月** —— 选几号，也可以选「末」（每月最后一天，29/30/31 号自动对上）
- **一次性** —— 挑一个具体日期，做完就结束，不重复

### 打勾、看进度

- 今日页每张卡片下面就是它的步骤，**点一下就勾上**
- 每勾一步，进度条和百分比会涨
- 全部勾完 = 100%，卡片会变淡
- 不想分步骤？那就只填名字，点卡片右上角的圆圈直接完成

### 三个数字

- 卡片右上角的 **%** —— 这一件事做完了多少
- 今日页右上角的**圆环** —— 今天所有事加起来做完了多少
- 设置页的**总完成度** —— 历史累计（勾过的步数 / 总步数）

### 看别的日子

底部 **日历** → 点任意一天。有事的日期下面有小圆点：
蓝点 = 还有没做完的，绿点 = 做完了。

## 三、提醒是三层，从软到硬

| 层级 | 什么时候响 | 靠不靠谱 |
|---|---|---|
| ① 页面内弹窗 + 提示音 | 页面开着、在前台的时候 | 前台一定响；切后台会被手机限制，可能晚一点 |
| ② 系统通知 | 页面在前台 + 你授权了通知 | 手机浏览器限制多，当个辅助 |
| ③ **系统日历闹钟** | 导出到日历后，系统自己响 | **最可靠，手机静音也能响** |

所以真正靠谱的做法是 **① + ③**：

1. 建好任务，填好「开始前提醒」和「快截止时再提醒」
2. 点今日页下方的 **「同步」**（或者去设置页选「未来 7 天 / 30 天」）
3. 手机会下载一个 `fishtodo-日期.ics` 文件
4. **点开这个文件** → 选择你的日历 App → 导入 / 添加
5. 到点系统就会弹通知、响铃

> 💡 建议每周同步一次。因为日历里存的是「具体某天某时」，不是无限重复。
>
> 💡 「快截止提醒」在日历里是固定会响的（日历不知道你有没有做完）；
> 在 App 里是**没做完才响**。两个配合着用最舒服。

## 四、安全 / 备份

- 数据只在你手机浏览器的 `localStorage` 里，**不会上传到任何地方**
- 换手机、清缓存、清数据之前，去 **设置 → 备份数据** 导出一个 json
- 新手机上：**设置 → 恢复数据**，选那个 json

## 五、常见问题

**打开是白屏 / 一直转圈？**
换个浏览器（Chrome / Edge / 夸克），旧的系统 WebView 可能不支持。

**点了「同步」没下载？**
部分浏览器对本地文件的下载有限制。换个浏览器，或者把页面放到网址上（方式 B）。

**勾了任务，关掉再开就没了？**
说明浏览器禁用了本地存储（比如无痕模式）。换成普通模式打开。

**提醒没响？**
网页关掉以后就不会再提醒了 —— 这是浏览器的限制，不是 bug。
要真响铃，走「同步到日历」那条路。

**日期算错了？**
检查一下手机的系统日期和时区。
